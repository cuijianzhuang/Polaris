# 用户启用与禁用

用户列表「状态」列提供独立开关，只切换该行用户，和批量勾选无关。请求期间锁定当前开关，服务端确认后更新显示；请求失败保留之前的显示。开关开启表示没有被手动禁用，到期、流量用尽、IP 超限等限制仍然生效。

`PUT /users/:id/state` 接收 `{"enabled": true|false}`，只修改该普通用户的手动状态，保留凭据、配额、授权和套餐。接口需要用户写权限，不允许用它修改中转等用途的服务账号。修改提交后发布关联节点的配置，页面保存成功不代表所有节点已经应用。

禁用后，目标用户从节点授权列表移除；其他用户应保留自己的凭据和授权。Xray 支持的协议通过用户 API 增删；不支持动态用户的协议会重载。sing-box 没有公开的用户管理 API，采用由 Agent 等待结束再启动的受控重启，启动失败进入配置回滚。更新 sing-box 用户时已有连接可能短暂中断，客户端需要重连；不能把进程仍存活当作 SIGHUP 已完成重载。

如果其他账号状态正常但持续无法连接，需核对：

1. 受影响节点的期望版本、已应用版本、同步错误和内核日志；不能只看用户状态。
2. 对应客户端实际使用的 UUID/密码是否属于该账号，是否误用了被禁用账号的订阅或共用的订阅组。
3. 实际中转、CDN、Tunnel 和出口是否正常。同一条共享链路故障会同时影响多个用户和内核。

排查时仅提供版本号、错误文字和脱敏的配置关系；不要公开订阅 Token、UUID、密码、私钥或 Tunnel Token。

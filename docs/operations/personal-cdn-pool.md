# 用户中心的个人优选地址池

用户登录 `/u` 后，在「维护个人优选 IP／域名」选择本人获授权的 CDN 配置。

- 手动列表支持添加、文本／CSV 文件批量导入（换行、逗号或空白分隔）、删除、逐条启用和禁用。每份配置最多 32 个手动地址；只接受公网 IP 或完整域名，不含端口、协议或路径。添加或导入后点击保存，草稿修改期间需先保存才能操作地址。切换配置会提醒丢弃未保存内容；当前配置和端口在刷新后保留。
- 选择实际入口端口后可逐条检测，结果来自面板网络，验证连接地址的 DNS、TCP、HTTPS TLS 和传输握手，使用与订阅一致的入口目标。连接优选 IP 时不会额外要求 SNI 域名先解析，但仍校验证书及 SNI 身份。它不等同于用户网络测速，也不验证代理认证。失败结果按本人、配置、入口和实际协议／端口／SNI／Host／路径／入站安全配置保存；重新检测成功后恢复使用，启用按钮不会清除失败结果。可批量检测当前端口所有已启用地址，界面显示进度；只检测选中入口，点击停止后结束当前地址，不再开始下一个。失败原因与时间直接显示在地址下方。
- 自动优选通过用户中心生成的官方 `cf-ip-probe` 命令安装。支持 Cloudflare HTTP／HTTPS，默认每小时运行。命令使用面板 API 地址、独立用户实例和绑定端口；OpenWrt 去掉 `sudo`。令牌仅在创建时随命令显示。
- 自动结果可通过「保留为手动」加入手动草稿，保存后不再受自动刷新替换。手动地址可逐条移除；如果同一地址仍在自动结果中，可禁用以阻止其进入订阅。
- 每份配置有一个专用上报令牌，可重置或撤销。重置会立即使旧令牌失效；撤销停止后续上报，已有自动结果保留。删除账号、停用账号或移除配置授权后，令牌不能继续上报。用户不能操作其他账号的令牌。

手动列表使用既有 `User.CDNPreferred`；自动结果、个人禁用和连通性检测保存在新增 `User.CDNPool`，由 AutoMigrate 添加字段。所有池更新先获取共享报告写锁，再读取最新账号，只更新对应部分。自动上报不写公共 `CDNIPReport`，也不会修改公共配置、手动列表、禁用规则或已知检测失败。

订阅先使用通过筛选的个人手动地址和当前端口自动地址（去重），没有可用个人地址再使用公共地区／运营商池。禁用或检测失败的个人地址即使在公共池中也不会重新出现。公共节点检测失败的地址同样过滤，全部失败也不恢复原列表。没有可用池地址时沿用入口回源地址，但回源地址本身仍须通过禁用和检测规则。

仅替换订阅中的连接地址，沿用现有入口端口、SNI、Host 和传输配置。未开启订阅展开、或入口设置了固定地址时继续遵守入口设置。

## 过期与检测上下文

自动结果按端口分别记录最后上报时间和测速协议。默认保持旧行为「继续使用最近结果」，可切换为「回退公共池」，设置 1–720 小时（默认 24 小时）。只有自动结果过期；可用手动地址仍优先，个人池无可用地址时使用公共池。一个端口的新上报不会刷新其他端口的有效期。协议改变后，旧协议的测量不再用于新协议。

检测只影响对应入口。入口的协议、端口、SNI、Host、路径或入站安全配置改变后，旧指纹不再匹配，需要重新检测。旧版本仅按端口保存的检测缺少完整上下文，升级后作为未检测处理并提示重新检测。一次部分完成不会解除同一配置的已知失败，完整传输握手成功才恢复；较早发起的检测不会覆盖较新结果。浏览器断开造成的取消不会记为地址故障。

## 订阅地址预览

点击「刷新预览」查看已保存配置在当前网络、地区／运营商选择下的入口地址。它复用实际订阅的授权、账号状态、节点配额和入口展开逻辑，显示手动／自动／公共／入口来源、个人池或公共池模式，以及禁用、检测失败、自动过期、前 N 个等筛选原因。每个入口同时展示实际端口、SNI、Host 和路径，不返回 UUID、密码或订阅令牌。客户端格式及全局订阅处理规则可能进一步筛选。

## 多窗口编辑

每份个人配置有独立的编辑版本，只覆盖手动列表、禁用项及过期设置；自动测速、检测结果或令牌变更不影响编辑版本。保存缺少版本返回 428；其他窗口已修改内容时返回 409，拒绝覆盖且保留当前页面草稿。先复制草稿，再使用「重新加载服务器内容」对照处理。旧页面升级后需要刷新一次获取版本。

## 接口

用户中心接口均需要登录 Cookie；POST 还需要 `X-Polaris-Portal: 1`：

- `POST /u/cdn-preferences`：`{profileId, version, addresses: string[], disabled?: string[], stalePolicy?: "keep" | "fallback", staleHours?: number}`。原子校验版本，更新本人该配置的手动列表及可选禁用／过期设置。
- `GET /u/cdn-state?profileId=...`：读取本人的最新 `version`、地址、池设置和授权入口，禁止缓存。
- `POST /u/cdn-pool`：`{profileId, action: "pair" | "revoke" | "check" | "preview", port?: number, address?: string, endpointId?: string, context?: string}`。创建／重置令牌、撤销令牌、检测已保存地址或读取订阅预览。检测需指定授权入口 `endpointId`，可同时提交入口 `context` 指纹；入口配置已改变时返回 409。检测连接禁止访问私网、回环、链路本地及 CGNAT，包括域名解析后的实际目标。

官方程序继续调用 `POST {api}/cdn-profiles/{id}/preferred-ips` 和 `GET {api}/cdn-profiles/{id}/ip-candidates`。个人令牌只可访问这两个接口，且限定配置、来源名称和测速端口，不能访问用户、订阅、设置或其他管理接口。客户端传入的用户 ID 不参与所有权判断。

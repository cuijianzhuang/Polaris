# 用户中心的个人优选地址池

用户登录 `/u` 后，在「维护个人优选 IP／域名」选择本人获授权的 CDN 配置。

- 手动列表支持添加、文本／CSV 文件批量导入（换行、逗号或空白分隔）、删除、逐条启用和禁用。每份配置最多 32 个手动地址；只接受公网 IP 或完整域名，不含端口、协议或路径。添加或导入后点击保存。
- 选择实际入口端口后可逐条检测，结果来自面板网络，验证 TCP 和 HTTPS TLS 连通性。它不等同于用户网络测速，也不验证代理认证。失败结果按地址和端口保存在本人池中；重新检测成功后恢复使用，启用按钮不会清除失败结果。
- 自动优选通过用户中心生成的官方 `cf-ip-probe` 命令安装。支持 Cloudflare HTTP／HTTPS，默认每小时运行。命令使用面板 API 地址、独立用户实例和绑定端口；OpenWrt 去掉 `sudo`。令牌仅在创建时随命令显示。
- 每份配置有一个专用上报令牌，可重置或撤销。重置会立即使旧令牌失效；撤销停止后续上报，已有自动结果保留。删除账号、停用账号或移除配置授权后，令牌不能继续上报。用户不能操作其他账号的令牌。

手动列表使用既有 `User.CDNPreferred`；自动结果、个人禁用和连通性检测保存在新增 `User.CDNPool`，由 AutoMigrate 添加字段。所有池更新先获取共享报告写锁，再读取最新账号，只更新对应部分。自动上报不写公共 `CDNIPReport`，也不会修改公共配置、手动列表、禁用规则或已知检测失败。

订阅先使用通过筛选的个人手动地址和当前端口自动地址（去重），没有可用个人地址再使用公共地区／运营商池。禁用或检测失败的个人地址即使在公共池中也不会重新出现。公共节点检测失败的地址同样过滤，全部失败也不恢复原列表。没有可用池地址时沿用入口回源地址，但回源地址本身仍须通过禁用和检测规则。

仅替换订阅中的连接地址，沿用现有入口端口、SNI、Host 和传输配置。未开启订阅展开、或入口设置了固定地址时继续遵守入口设置。

## 接口

用户中心接口均需要登录 Cookie 及 `X-Polaris-Portal: 1`：

- `POST /u/cdn-preferences`：`{profileId, addresses: string[], disabled?: string[]}`。仅更新本人该配置的手动列表及可选禁用列表。
- `POST /u/cdn-pool`：`{profileId, action: "pair" | "revoke" | "check", port?: number, address?: string}`。创建／重置令牌、撤销令牌或检测已保存地址。检测连接禁止访问私网、回环、链路本地及 CGNAT，包括域名解析后的实际目标。

官方程序继续调用 `POST {api}/cdn-profiles/{id}/preferred-ips` 和 `GET {api}/cdn-profiles/{id}/ip-candidates`。个人令牌只可访问这两个接口，且限定配置、来源名称和测速端口，不能访问用户、订阅、设置或其他管理接口。客户端传入的用户 ID 不参与所有权判断。

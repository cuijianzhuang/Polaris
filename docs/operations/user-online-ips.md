# 用户活动与在线 IP

用户列表区分两种证据：

- **在线**：有未过期的客户端来源 IP 报告。同一地址跨节点去重；IPv4 映射 IPv6 和带端口地址会规范化为 IP。
- **近期活跃**：近两分钟有流量或活动记录，但无法确定当前来源 IP。流量记录不能用于推断 IP 数量。

在线 IP 列显示计入 IP 限制的数量与配置上限，0 为不限。受信任地址不计入，列表同时标明免计数量。CDN 边缘地址也不计入；只有 CDN 地址时显示“未识别”，客户端地址与 CDN 地址混合时显示数量下限 `≥N`，不把边缘地址当作用户设备。

“已过期”表示曾收到来源 IP，但报告超过有效窗口；“未识别”表示没有有效客户端来源。点击该列可查看具体地址、来源节点、上报时间及免计原因。详情每十秒刷新，编辑用户资料时不会覆盖未保存的表单。

来源 IP 采用现有的 75 秒有效窗口，不用数据库中保存的旧地址补齐实时结果。sing-box 当前通过连接日志记录来源，新连接停止后该记录可能先过期，而长连接仍在产生流量，因此此时显示“近期活跃 / 已过期”是信息不足的提示。此修改不将日志采集升级为完整连接生命周期追踪，也不把“最近有流量”等同于“仍有连接”。

内核不支持来源 IP、采集暂时失败或面板重启后缺少有效报告时，也可能暂时无法展示客户端 IP。需要可靠的真实 IP 时，还应核对对应协议、CDN／中转入口是否支持并正确传递客户端地址。

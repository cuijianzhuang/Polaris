# 用户活动、来源 IP 与使用节点

用户列表分别显示连接证据与客户端来源是否可见：

- **在线**：有 75 秒有效窗口内的用户连接来源报告，包括只有中转或 CDN 来源的报告。
- **近期活跃**：近期有活动记录，但缺少有效连接来源报告。活动记录不能用于推断来源 IP、设备数量或当前使用的节点。
- **未识别**：有效报告只有节点／中转／CDN 地址，客户端来源未知。这不等于用户离线，也不表示客户端数量为零。
- **已过期**：以前收到过来源报告，但已经超过有效窗口。

## 在线详情

详情按证据分层展示，每十秒刷新，不覆盖用户编辑器中未保存的资料。

1. **当前上报连接的节点**：仅包含这个用户有新鲜有效报告的节点，显示节点名、稳定 ID 对应的详情链接和最近上报时间。已配置但未上报的目标不加入这份活动列表。
2. **客户端来源 IP**：节点实际观察到的非节点／CDN 地址，以及哪些节点上报了它。显示本地城市库和 ASN 库查询出的地区与运营商，不向第三方发送 IP。
3. **中转与 CDN 来源**：保留被排除地址作为排查证据；已知节点地址显示地址归属节点，和实际上报节点分开。

同一 IP 跨节点去重，IPv4 映射 IPv6 与带端口地址会规范化。受信任地址、已知节点地址与 CDN 地址不计入 IP 限额；客户端与中转报告混合时数量显示 `≥N`。不把配置关系当作客户端 IP，不把订阅请求或管理员访问面板的 IP 当作当前代理连接来源。

## 已有链路与外部中转声明

面板从已启用的链路相邻跳自动读取中转目标。例如 A → B → C 产生 A → B 和 B → C，不推断 A → C。停用链路不加入当前配置提示。

节点编辑器的“外部中转目标”用于补充在 Polaris 之外手工配置的中转关系。仅保存元数据，不创建端口转发、不改变订阅、不自动启用真实 IP 传递。目标必须是已有的其他节点，最多 64 个；空数组清除，旧客户端未传该字段时保留。被其他节点手动声明为目标的节点需先解除声明才能删除。

详情中的“已配置中转目标”合并已有链路和手动声明，并去重。它表示配置，不证明某次连接经过全部目标。即使同一用户同时出现在 A、B，也不能把 A 看到的真实客户端地址当作中转 IP；手动声明不会改变 IP 免计规则或绕过限额。

## 中转后的真实 IP

中转节点重新建立到落地的连接时，落地默认只看到中转地址。仅凭这个地址、地理位置、延迟或并发上线，无法还原客户端来源。

兼容的受管原样 TCP 链路可使用现有的配对 PROXY v1/v2 支持：

1. 确认落地是兼容的 Xray TCP 入站、Agent 已升级、链路类型受支持。
2. 在落地入站“中转与访问控制”中配置来源保护与 PROXY 协议。启用后直连客户端不能使用该入口，应保留独立直连入站。
3. 编辑已有入站时，通过独立的“应用访问策略并下发”操作提交；这使用专用验证接口，不会顺带保存其他未提交资料。
4. 界面提示策略已保存、等待节点应用；确认链路各跳应用成功后，再通过真实客户端连接验证来源报告。

来源保护、Agent 能力、独立端口、共享回落、隧道、传输和内核兼容性仍由服务端检查，不能通过普通入站保存绕过。暂不支持的链路需要入口节点直接采集来源，不能靠配置声明生成真实 IP。

## 长连接与采集能力边界

75 秒窗口不使用数据库旧地址补齐实时结果。sing-box 当前基于连接日志记录来源，新连接停止后记录可能过期，即使长连接仍在传输；这时需要改进采集或检查内核能力，不能延长旧地址保留时间来声称准确在线。

旧版 Xray 的在线 IP 表也存在长连接地址按时间淘汰的行为；较新版本改为连接生命周期计数。若地址刚连接时可见、随后消失，请先核对节点实际运行的 Xray 版本并复现长连接。面板不根据流量字节数恢复历史 IP，也不把某个旧地址映射给另一条中转连接。

内核不支持、采集暂时失败、面板重启或共享状态故障，也可能造成来源暂不可见。本次展示改进没有给不支持的内核新增连接生命周期追踪。

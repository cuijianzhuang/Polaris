# 手动维护 CDN 优选域名

进入「链路与路由 → CDN 配置档」，选择配置档，在「手动优选域名」卡片点击「维护域名」。一行填写一个完整域名，例如 `best.example.com`，不带 `https://`、端口、路径或通配符。保存时自动去掉首尾空白、末尾句点，统一为小写并去重。新建和编辑配置档也有独立的同名输入框。

手动域名只属于当前配置档，不会随着 Cloudflare 共用测速点传播到其他配置档。测速点上报和来源 URL 刷新会保留这些域名；即使 URL 拉取过程中修改了手动列表，拉取完成后也会使用最新手动列表。维护域名只提交手动列表，不会提交浏览器中可能已过时的测速结果或其他配置。

需要在配置档的「编辑」中开启「订阅按优选 IP 展开（一个 IP 一个节点）」，域名才会作为订阅连接地址使用。若「订阅取前 N 个」大于 0，手动域名追加到前 N 个自动地址后，不占用 N 的名额；TLS SNI 和 HTTP Host 仍使用对应入口的回源域名。入口显式指定了连接地址时保留原有行为，不按优选列表展开。开启节点检测时，手动域名也遵循现有的可达性筛选。

从列表删除或清空后保存即可取消手动保留。如果该域名仍出现在来源 URL 中，下次自动刷新可能再次带入，但不会自动变成手动保留项。测速点和来源 URL 的结果显示在原有优选 IP 区域；「临时优选地址」输入框内的内容仍可能被自动更新替换。

## API

管理员可调用 `PUT /cdn-profiles/:id/pinned-hosts`：

```json
{"pinnedHosts":["best.example.com","best2.example.com"]}
```

传 `{"pinnedHosts":[]}` 清空手动列表。省略字段、传 `null` 或非法域名会返回 400，不修改原列表。只有原有配置管理权限的管理员可维护；仅有 `cdn:ips:write` 权限的测速令牌不能维护域名。

新建或完整编辑配置档也接受显式的 `pinnedHosts` 数组。未提供该字段的旧客户端仍按原有混合列表规则识别手填域名，无需新增数据库迁移或更新 Agent。

# CDN 优选地址定时检测

在「链路与路由 → CDN 配置档 → 优选地址与订阅预览 → 定时检测」设置周期。默认关闭，可选每 5、15、30、60、360 或 1440 分钟；API 支持 5–1440 分钟，0 表示关闭。

保存后后台每分钟调度到期任务。覆盖该配置档所有已启用的关联 CDN 入口，按实际 HTTP/HTTPS、端口、SNI、Host、路径和传输方式分别检测优选 IP、固定域名及入口指定地址。手动禁用的地址跳过，失败地址仍会复检。入口配置无效时显示原因，不把配置错误记成所有地址失败。

检测与页面手动「检测」共用判定和保存逻辑：明确失败的地址从对应入口订阅中排除，复检通过才恢复。部分完成不会清除已有失败。地址和失败记录仍保留在管理页；手动重置检测仍可显式恢复到未检测状态。

任务来自面板网络，只验证 DNS、TCP、TLS 和传输握手，不使用普通用户凭据，也不证明客户端网络、代理认证、上下行或 UDP 可用。这与 Agent 的端口 TCP 检测和 cf-ip-probe 用户网络测速不同。

页面启用后每 10 秒刷新本轮进度、失败数、最近检测时间和下次检查/续批时间。页面关闭不影响后台执行。大量地址分批续检，每批最多 8 个，每次探测最长 20 秒，批次最长 2 分钟；未完成时等待至少 1 分钟续批，整轮完成后再等待所设周期。其他到期任务和网络超时可能延后实际开始时间。

进度保存在数据库中，独立于最多 64 条的详细诊断历史。面板重启可继续未完成轮次；遗留任务租约在 3 分钟后可重新领取，多实例共享数据库时同一配置档只有一个有效任务。关闭或更改周期立即使旧任务失去保存权限，保留已有结论；已经发出的网络请求会在取消或超时后结束。面板关闭、批次超时导致的取消不记作地址失败。

关联入口或候选地址改变后，下个批次会重新计算整轮任务。地址通过检测的结论仅适用于检测时的入口配置；更改协议、端口、SNI、Host、路径或入站安全设置后，沿用现有指纹规则重新判断。

管理员接口：`PUT /api/v1/cdn-profiles/:id/check-schedule`，请求为 `{"intervalMinutes":15}`。检测状态包含在 `GET /api/v1/cdn-profiles/:id/address-tools` 的 `schedule` 中。测速上报令牌不能修改计划。

# AI 助手与用户客服

AI 为可选功能，升级后默认关闭。由超级管理员在「系统 → 设置 → AI 助手」配置；使用服务商 API 会产生该服务商的调用费用。

## 模型服务与实时模型列表

内置 OpenAI、Claude、DeepSeek、Gemini、通义千问预设，也可选择自定义地址。OpenAI、DeepSeek、Gemini 和通义千问使用 OpenAI Chat Completions 兼容格式；Claude 使用原生 Messages API。自定义服务可选择这两种格式之一，适用于中转 API 与提供兼容接口的本地模型。

1. 选择服务商，填写 API 基础地址与 API Key。地址应为 API 根路径，如 `/v1`，不要填写具体的 `/chat/completions` 或 `/messages`。
2. 打开设置时会使用已保存的配置获取模型列表；填写新密钥后也可获取，或点击「刷新模型列表」。新地址和新密钥的发现请求需要管理员近期身份验证。
3. 从服务商实际返回的列表选择模型，或手动填写模型 ID。服务商提供发布时间时按时间降序排列；未提供时间时按名称排序。刷新列表保留当前选择，避免自动切换费用或能力不同的模型。列表最多请求四页，实际聊天权限与兼容性通过连接测试确认。
4. 保存后点击「测试模型连接」。它会调用一次简短的文字生成，检查密钥、模型与接口格式；无需先开启整个助手。
5. 开启 AI 助手。如需面向用户提供客服，单独开启「开放用户中心 AI 客服」。

本地或内网服务须明确勾选「允许 HTTP／私网模型服务」。这个选项独立于订阅来源的私网访问开关；元数据地址、链路本地地址等仍会被拒绝。公共服务建议使用 HTTPS。密钥加密存储，不通过设置读取接口返回；更换服务商、地址或格式时，需重新填写密钥或明确清除原密钥。认证失败、服务商限流及重定向返回不会把上游响应原文或密钥展示给用户。

## 管理员功能

- **创建入站**：「入站 → 新建入站 → AI 辅助创建与检查」。描述需求，AI 从当前节点内核的协议、传输与安全能力中选择组合。返回草稿经过本地结构、内核能力、已有证书与面板端口校验；点击「应用到入站表单」后仍需核对授权、CDN、证书和高级配置，再按原流程保存。密钥和用户凭据由现有流程生成。
- **配置检查与故障诊断**：可在入站编辑器选择对应任务，也可在 AI 设置页的运维助手中选择节点、入站和日志。服务端收集状态与已保存的检测结果；保存的 CDN 入口还会复用已有兼容性与证书检查。连接通过、认证和业务传输是不同证据，AI 不会替代实际检测。
- **运维摘要**：汇总本次运维快照与最近 24 小时内最多 12 条工单，异常详情最多展示 24 条。汇总的统计范围与截断状态由面板提供。
- **工单辅助**：管理员打开工单后使用「AI 工单辅助」起草回复，再明确填入编辑框。替换已有文字需要确认；发送仍由管理员操作。

这些功能仅对超级管理员开放。模型服务没有执行命令、修改数据库、授权、计费或发布入站的工具。请求携带的选定节点、入站和工单也由服务端读取和校验。

## 项目知识库

知识库直接来自随当前版本内置的 `docs/user-guide.md` 与 `docs/operations/*.md`，通过标题和关键词匹配相关段落，无需部署向量数据库或额外调用嵌入模型。文档随着程序版本更新；站点 FAQ 可在设置中即时维护。

每次回复附带本次检索的文档标题、路径和摘录，供人工核对。用户客服只检索用户手册中的客户端使用、用户中心章节和管理员公开维护的站点 FAQ；管理端可检索完整运维文档。文档和日志作为数据处理，不能改变服务端权限或触发操作。

## 用户中心客服与人工工单

开通后，用户中心导航和首页帮助卡片出现「AI 客服」。只有登录用户可以使用；服务端沿用订阅授权与发布筛选，只提供本人套餐状态和有权限查看的节点状态，不提供订阅链接、代理凭据、其他用户资料或管理员配置。

用户可以多轮提问、停止请求或开始新对话。对话仅保存在当前页面内存，默认不写入服务端聊天记录；发送给服务商的文本会处理常见凭据、订阅链接、IP 和邮箱，但仍应避免粘贴敏感资料。服务商自身的数据保留规则取决于管理员选择的服务。

若工单已开放，「转人工客服」可填入问题及 AI 建议的摘要。用户核对后明确点击提交，再走原工单及通知流程。模型无法自动提交工单、承诺退款或更改套餐。

## 额度与故障处理

默认每用户滚动 24 小时最多 20 次请求，全站 300 次；管理员可调整。单用户每分钟最多 4 次、超级管理员每分钟最多 8 次，模型列表每分钟最多 5 次。模型输出默认上限 4096 tokens，可配置为 256–8192；推理模型的额度包含思考过程。每个实例同时最多处理 4 个生成请求，单次请求最长 45 秒。失败和取消的尝试也可能占用请求额度；服务商计费以其记录为准。

连接测试失败时依次核对基础地址、接口格式、密钥权限和模型 ID。本地地址还需检查私网选项；不支持列举模型的自定义服务可手动填写名称。慢请求可停止，离开页面会取消；切换节点、修改草稿后，旧结果会被丢弃。设置保存使用版本校验，并发编辑冲突时保留当前草稿，重新加载前提示确认。

# CI 调度、失败材料与共用 UI 规范

## 按改动调度

`.github/scripts/ci-scope.py` 是浏览器套件列表与 PR 范围选择的来源。文档改动只运行轻量检查；已明确归属的页面或浏览器脚本运行对应套件及前端构建。Go、协议、共享 UI、依赖、工作流和未知路径保守运行全量。重命名、删除、无有效差异或无法解析基线也不会默默跳过检查。

发布调用始终选择完整范围。只有真正完成全量 PR 浏览器／PostgreSQL 检查的 Git 树才生成可复用证明；局部检查的 PR 不生成证明，不能让发布借用它跳过重要回归。调度脚本有独立单元测试，新增页面若未映射会自动回退全量。

## 浏览器失败材料

CI 通过 `PYTHONPATH` 和显式开关 `POLARIS_BROWSER_DIAGNOSTICS=1` 为 Python Playwright 用例启用诊断，包含 Go 测试启动的 Python 子进程。异常退出时，在浏览器关闭前保存截图、脱敏网络事件和操作时序 trace，作为 `browser-evidence-*` artifact 保留 7 天。

材料有意保留隐私边界：网络日志只记录方法、状态、来源、路径和查询参数名称，不复制请求体、Cookie、授权头或查询值；订阅路径的 Token 也会隐藏。日志只保留最近 500 个事件。截图隐藏输入框、代码／复制区及二维码。trace 保留操作、时间和调用位置，去除输入参数、结果、页面快照、响应体和资源内容，不记录原始凭据；因此 trace viewer 不提供完整 DOM 回放，需结合截图和 CI 断言定位。

原始 trace 只写到不会上传的临时目录，清理成功后才复制到 artifact 目录；脱敏失败不会上传原始文件。成功用例的 trace 直接丢弃。无可用页面的失败仍保存脚本与上下文数量，具体异常保留在原有 CI 测试输出。

## 共用 UI 规范

`internal/uitheme/assets/tokens.css` 是面板和用户中心共用的字体、颜色、间距、圆角和控件尺寸来源：

- React 入口直接导入同一 CSS；Go 用户中心、登录页直接嵌入同一文件。
- 字体优先使用 Apple／系统 UI 字体，代码使用共用等宽字体栈。
- 默认浅／深表面和主色来自共用变量；桌面普通控件 40px、紧凑控件 34px，移动端触控目标至少 44px。
- 基础圆角统一为 6／10／14px，间距使用 4px 系列。

两套应用保留各自布局：管理端适合密集操作，用户中心适合订阅与用量阅读。暖灰、午夜、黑金及自选强调色继续覆盖默认色，不会被共用基础规范强制重置。Docker 前端构建显式复制这份共用资源，避免本地能构建但 CI 缺文件。

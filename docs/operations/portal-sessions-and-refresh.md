# 用户中心会话、节点状态与设置刷新

## 登录设备

个人中心提供「登录设备」，显示当前设备、登录方式、连接地址及最近活动。可退出单个设备、当前设备或全部其他设备。记录只对当前用户可见；撤销请求需要用户中心 Cookie 和 CSRF 请求头。

用户中心 Cookie 必须对应服务器端未撤销、未过期的会话，并与当前登录身份及订阅指纹匹配。退出其他设备会推进本用户的会话版本并续签当前 Cookie，已撤销设备的进行中续签不能恢复会话。这些操作不重置代理 UUID、密码或订阅 Token。

升级后旧的无服务器端记录 Cookie 需要重新登录一次。会话及其版本不进入备份；恢复备份会清除现有用户会话。失效记录每小时清理，列表最多展示 100 个，超出部分仍能通过「退出其他设备」一并撤销。

## 节点证据

「可用节点」只列当前账号被授权、仍在订阅发布的节点，状态由已有后台检测记录推导：

| 显示 | 依据 |
| --- | --- |
| 业务已验证 | 现有端到端业务验证通过，且配置、部署和结果仍有效 |
| 连接通过 | 近期服务端连接或节点间网络检查通过，尚无完整业务证据 |
| 待检查／待复检 | 缺少近期证据、配置同步中，或结果过期 |
| 暂不可用 | 已知离线、服务停止、近期检查失败或配置不兼容 |

详情拆分在线状态、连接检查、业务验证及检查范围。二维码默认折叠。页面可见且详情关闭时每 30 秒刷新，也可手动刷新。刷新接口重新校验账号、地区、运营商和订阅发布范围，仅返回状态，不返回节点凭据或启动诊断。新增节点提示重新加载，已撤销授权的节点从当前列表移除。读取失败保留旧结果并允许重试。

### 自动与主动连接检查

节点详情提供「检查连接」，节点页提供可关闭的「自动检查连接」。自动模式每 12 秒选择一个当前筛选范围内、5 分钟内未检查过的节点，页面隐藏、离开节点页或打开详情时暂停。偏好保存在当前浏览器。现有后台入站巡检继续每两分钟运行；页面自动检查的观察点是面板，目标为当前用户订阅里的实际地址及端口，包含 CDN 和中转入口。

主动检查重新验证当前账号、地区、运营商与节点发布状态，不接受客户端提供目标地址。TCP 协议执行连接；普通 TLS 按订阅的 SNI、ALPN 与证书策略握手。REALITY 只检查 TCP，明确不验证公钥、Short ID 或认证；UDP 协议明确标为不适用。检查不创建临时用户、不重启内核、不使用普通用户代理额度。

结果按用户及完整节点链接指纹缓存 5 分钟，不写入全局入站健康状态，避免一个用户的优选地址影响其他用户。限制账号、全局及同一目标的频率，目标 15 秒内不重复拨号。底层连接逐个校验解析地址，拒绝内部、回环及元数据网络；失败返回分类说明，不暴露底层内部错误。关闭自动模式后仍可手动检查。

这些状态不等于用户本地网络可达性；端口检查不能证明代理认证、上下行传输或 UDP 正常。尚无业务适配的协议保留「尚未验证」，不会伪造成功。

## 草稿与慢网络

订阅规则模板、节点名称和订阅设置接入离开前保存／放弃／继续编辑流程。编辑模板时后台刷新不覆盖草稿；保存失败或服务器版本冲突时保留输入。更新和删除模板携带 revision，旧版本返回 HTTP 409；可明确选择重新加载服务器内容。兼容不传 revision 的旧 API 客户端，其写入仍推进版本，但不提供客户端并发编辑保护。

通用列表读取按依赖项取消旧请求；同一组依赖下，刷新串行并最多合并为一个后续请求。慢响应先展示，再执行合并刷新，避免轮询不断取消请求。读取超过 20 秒会中止并显示错误；相同查询保留上次结果，切换用户、节点或查询条件后不会显示旧依赖的数据。

## 验证

`portal_entry_check_test.go` 覆盖实际 TCP／TLS、证书失败、UDP 不适用、内部地址拒绝、授权、缓存隔离及限频。`portal_sessions_test.go` 覆盖退出、重放拒绝、跨用户隔离、存储失败、过期和撤销后续签；`subtemplate_revision_test.go` 覆盖并发编辑冲突与失败回滚。真实用户中心浏览器用例覆盖 Chromium／WebKit、移动／桌面、明暗主题、状态刷新与设备退出。`drafts-refresh-ui-smoke.py` 使用受控延迟和浏览器时钟覆盖草稿、保存失败、冲突、慢响应串行与超时重试。

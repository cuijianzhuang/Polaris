# 后台账号与角色

社区版功能。设置 → 账号安全 → 后台账号与角色，由超级管理员完成高权限确认后创建账号、分配角色/节点、重置密码或删除账号。

| 角色 | 范围与操作 |
| --- | --- |
| 超级管理员 | 全部功能，包括后台账号、API 令牌、密钥、备份和支付设置 |
| 节点运维 | 必须指定节点；查看状态/历史/日志、强制同步、配置回滚、重启内核；不允许安装 Agent、改内核版本、查看原生配置或管理用户 |
| 只读运维 | 必须指定节点；仅在线、资源和最后在线时间摘要，不访问完整节点对象、配置、日志或 WebSocket |
| 客服 | 全部用户的状态/配额摘要，读取/回复/关闭/重开全部工单；不读取数据库中的代理凭据或订阅链接，不修改用户权益，不删除工单 |
| 财务只读 | 全部订单的金额、支付状态、时间，以及服务器成本；不读取订单访问密钥、支付凭证、客户联系方式、供应商备注，不退款/发货/改支付设置 |

这是固定角色方案：客服和财务覆盖整个相关业务，尚不支持按客户/订单分组授权或自定义权限。工单内容由用户自行输入，运维日志可能包含业务信息；分配这些角色前应按实际职责评估接触范围。新账号默认选客服，必须明确设置初始密码；节点角色未分配节点时不能保存。节点范围最多 200 个，不存在的节点会拒绝。

旧账号的空角色（包括旧表新增列的 NULL 和旧备份）继续作为超级管理员，不会在升级时被自动降权。每个请求从数据库读取当前角色与节点范围；JWT 不作为权限来源。API 令牌和 Telegram 原有授权继续独立工作，新接口默认不向令牌或节点管理员开放。

角色/范围变化会增加 token version 并撤销全部会话；重新登录后使用新权限。密码重置也撤销旧会话，保留 TOTP。删除账号同时删除会话、Passkey、恢复码及 SSO 绑定。WebSocket 在发送新快照前重新确认会话版本；已开始执行的普通 HTTP 请求不会被追溯取消。

账号变更在跨实例数据库锁下重新核对操作者权限；不能降权或删除最后一个本地超级管理员，不能删除当前登录账号。管理操作写入审计，密码、TOTP 和恢复码不返回到账号列表。许可证因长期断网进入管理只读时，账号安全管理仍可执行，业务写入继续受原限制。

有限角色有独立工作台，只调用所需数据视图；节点运维复用已有节点界面和服务端节点范围检查。每个本地账号可以修改自己的密码、绑定 TOTP/Passkey、查看与撤销自己的会话，不能撤销别人的会话。超级管理员继续使用原后台布局。

验证覆盖 REST 默认拒绝、跨角色/跨节点访问、敏感字段投影、密码和角色变更后的旧会话、并发最后管理员保护、旧角色兼容、许可证断网时的安全撤销及 WebSocket 实际断开。浏览器回归覆盖手机/桌面、中英文和 Chromium/WebKit；它们不替代生产权限配置验收。

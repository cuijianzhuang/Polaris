# 服务器网卡流量与成本统计

服务器成本页的「近 30 天」按面板本地日期统计今天及前 29 天，不包含未来日期。统计采用节点配置的计费方式：出站、入站、期间上下行总量的较大值，或双向合计。「取较大值」比较整段期间的收发总量，不累加每日较大值。每 GB 成本使用同一口径，GB 沿用面板的 1024³ 字节口径。

页面同时展示入站、出站原始值、计费方式和有数据的日期数。零流量与未采集区分显示。有数据的日期不代表全天连续采集，也不代表已经覆盖完整 30 天。网卡统计包含服务器其他程序的用量，与用户套餐流量、服务商的计费记录可能不同；本周期手动校准不会倒推修改历史每日流量。

## 成本与币种

节点原价始终使用节点配置的币种。汇总本币通过下拉选择；切换时，界面按当前填写的汇率自动换算整张汇率表。例如本币 CNY、USD 汇率 7.2，改用 USD 后 CNY 汇率为 1/7.2。缺少目标币种汇率时先提示补充，不猜测汇率，也不修改节点原价。新增自定义币种可以在汇率表中填写后选用。本币自身汇率固定为 1，无效或重复的汇率不会保存。

本币、汇率和提醒天数在同一事务保存，并通过一次查询读取完整配置，避免多实例看到混合版本。小额月成本保留计算精度，每 GB 成本以未舍入月成本计算；金额仅在展示或汇总输出时按相应精度格式化。一次性费用不参与月度汇总。读取失败时页面显示错误并提供重试，不显示零成本或沿用旧汇总。

### 续费日期与并发

到期日按面板本地日历日期处理，当天结束后才自动顺延。按月、季度、半年、年续费保留原始续费日，目标月份没有该日时取当月最后一天；例如 1 月 31 日月付续费到 2 月末，下次恢复到 3 月 31 日。年付的 2 月 29 日在非闰年取 2 月 28 日，闰年恢复 29 日。停机漏跑后的自动顺延从原始续费日直接计算需要补齐的周期，不逐月累积日期偏移。

手动续费、自动顺延、提醒和成本编辑共享节点事务锁，锁内重新读取到期日及配置。每次成功的手动续费增加一个周期；多个巡检不会重复顺延已经处理的到期日。数据库写入失败返回错误或记录巡检错误，不发成功提醒；通知在提交之后触发。

成本记录带版本号，新版编辑器保存时提交读取到的版本。发生冲突返回 409，并保留未保存表单供用户核对，防止旧表单撤销刚完成的续费。未提供版本号的旧 API 客户端继续兼容，其编辑不具备此冲突检查。仅修改价格或备注会保留原始续费日；显式修改到期日会按新日期重新确定续费日。

原始续费日和版本号随数据库迁移、备份恢复保留。旧记录没有续费日时以当前到期日初始化，不猜测修复此前已经发生的日期偏移。本项只需要升级面板。

## 采集与去重

新 Agent 上报网卡累计值、来源标识和主机运行时间毫秒值。来源标识为主机启动 ID、接口名称及接口索引的摘要；Agent 自身重启保留相同来源。主机重启、增删或替换网卡时建立新基线，不把新接口启动以来的累计值重新记为新增流量。计数下降也只重设基线；来源变化边界的未观测流量无法准确还原，因此不会估算入账。

排除 loopback、常见 Docker/veth/bridge 和 tun/tap/WireGuard/Tailscale/CNI/Flannel 等虚拟接口，避免同一数据在宿主网卡和隧道接口重复累计。自定义接口名、特殊网络拓扑仍需结合主机和服务商记录核对。

不完整采样（读文件失败、数值无效、接口身份读取失败）不上报有效计数；观察到的真实零计数可以建立基线。相同来源下按主机运行时间去掉重复或乱序心跳。旧 Agent 缺少这些来源和顺序信息，兼容接收但不能提供同等的乱序保护，应同步升级。

Agent 另报独立的主机启动 ID 摘要，该值在网卡变化时保持不变。面板按节点、主机启动 ID 持久化已接收的最大运行时间，跨网卡来源切换也拒绝较旧或重复的采样；合法的网卡恢复使用更大的运行时间重新建立基线。观察到新的主机启动后，先前已观察到的启动 ID 标记为退役，其后续迟到心跳不能重新覆盖基线。首次出现且没有既往记录的启动 ID 仍需作为新来源建立基线，不能仅凭运行时间比较不同主机启动的先后。

接收进度、启动退役状态与基线、每日账本同事务提交，写入失败不会消耗重试机会。多面板实例共享这些记录，面板重启后继续去重；删除节点时一并删除其启动记录。只上报网卡来源标识的旧 Agent 继续兼容，但缺少跨网卡和跨启动的完整保护。应升级各节点 Agent 以启用新字段；服务端升级时不会据此改写旧流量历史。

## 原子入账

后端在事务中先锁定节点，再读取基线和计算增量。节点本周期总量、最新基线和每日账本同事务提交；失败时整笔回滚，下次心跳可重试，避免账本写入成功但基线失败造成重报。告警在提交成功后发送。

周期重置、手动校准和服务商同步也使用同一节点事务锁。跨过重置日后，首个心跳先开启新周期再入账；小时巡检重新读取锁定后的周期状态，不能清掉已经记入新周期的流量。重置保留网卡累计基线和每日历史，校准只修改本周期偏移量。心跳跨零点的未观测区间归入收到该心跳的日期与周期，不按时间比例猜测拆分。

校准基于锁内最新计数计算偏移，避免与心跳并发时重复计入增量。写入失败时返回错误，服务商校准的告警仅在事务提交成功后发送。

## 旧数据

旧版每日记录标记为待核对，不自动清零、折半或按新流量猜测修正。同一天混入旧 Agent 数据后仍保留旧版标记，避免把混合记录当作全部可信。升级需要同时更新面板和各节点 Agent；修复能保护后续采集，但不能仅凭旧汇总还原此前的真实用量。历史更正需要可靠的服务商或主机记录。

# 外部订阅节点资源与服务器引用

2026-10-25。订阅源解析属于专业版；公共仓库提供持久模型、引用解析、失败阻断及界面，`polaris-pro` 提供来源保存、拉取与组合订阅服务。部署必须同步升级两个仓库。

## 身份与刷新

每个来源拥有独立的节点资源 ID，不以名称或数组下标充当引用。刷新先按完整连接配置匹配（忽略显示名称、来源标签和地区），再匹配唯一的 `协议 / 地址 / 端口 / 传输类型`。因此改名、重排、明确的凭据或传输参数轮换保留 ID；地址、端口或协议改变视为移除加新增。多个账号共用端点且同时更换凭据时不猜测身份，旧引用保留为不可用，需要管理员重新选择。

完全相同连接配置的重复条目合并为一个资源。节点从来源移除时保留历史记录和引用，再出现且可匹配时恢复原 ID；只能手动清理无引用的已移除节点。每来源上限 5000 个资源输入，保留最近 100 次成功刷新的差异：新增、移除、变更、恢复，以及变化字段名称。差异不包含凭据旧值或新值。失败的网络刷新不替换最后一次成功数据；修改来源定义会先关闭旧缓存引用，成功解析后恢复。元数据编辑不重新请求网络。

拉取在事务外进行，提交、绑定和删除共用数据库锁；来源 revision 校验防止较早的并发请求覆盖较新内容。订阅组保存也参与同一锁，删除来源前检查订阅组与所有出站引用，包含停用的引用。

## 凭据

来源 URL、手动内容、解析缓存和节点完整连接配置使用现有 AES-GCM Box 加密。启动时迁移旧数据库，恢复旧备份时重新加密；跨密钥备份继续使用现有重新封装逻辑。API 返回域名及 hasUrl/hasContent，不回显 URL、原始内容或资源 payload；编辑时留空保留，填写新内容替换。来源错误不回显带 token 的请求 URL。节点预览只返回元数据，刷新差异只返回字段名。

服务器出站只保存 `source_ref + sourceNodeId`，在生成配置时解密解析，来源凭据轮换不需要逐个修改引用。发给 Agent 的配置继续走原有加密存储与受认证的下发通道。管理页面的配置预览脱敏；管理员显式查看原生运行配置仍具有查看连接凭据的权限。

## 出站与协议中转

- 订阅源「节点」可查看资源 ID、已移除节点、引用关系和刷新差异。
- 「引用」选择服务器和出站标签，创建服务器出站；可选已有入站，同时设置该入站的出站绑定，作为协议中转。
- 链路与路由的出站编辑器也可直接选择外部订阅节点。
- 中转入口的用户、授权、到期和流量计费继续使用本面板入站；不向本地用户分发供应商凭据。供应商配额由供应商独立统计。
- 已有出站绑定的入站不会被覆盖；已有链路路由的节点要求在路由中显式配置，避免冲突。本入口不创建 L4 透传隧道，不修改分享地址。

首版支持统一模型已有的 VLESS、VMess、Trojan、Shadowsocks、Hysteria2、SOCKS 和 HTTP，保存时校验节点内核及传输能力；其他协议仍可以通过订阅输出。无法完整表示的扩展不允许引用，包括当前尚未接入的混淆、Vision UDP443 和部分后量子选项。VLESS Encryption 服务器引用暂限支持版本的 Xray。新版 Xray 不再接受跳过 TLS 验证时，拒绝这种节点的引用。

来源停用、定义等待解析、节点移除、密文损坏或配置不兼容时，生成拒绝连接的路由，不继续使用旧凭据，不退回直连；依赖该出站的均衡组与 detour 路径也保守暂停。更新仍需 Agent 接收并应用配置；离线节点不能立即撤销正在运行的旧配置。

## 验证

Go 回归覆盖稳定身份、歧义轮换、恢复、过期提交、加密迁移、脱敏、元数据编辑、来源及节点删除保护、拒绝路由和备份；同一组关键接口在 PostgreSQL 上执行。浏览器脚本 `web/scripts/source-resources-ui-smoke.py` 检查 390/1440 宽度下的空白保留编辑、资源列表、移除筛选、差异与中转绑定。

`TestLiveSourceReferenceAuthBillingAndFailClosed` 在设置 Xray / sing-box / mihomo 二进制环境变量时运行真实内核，验证代理认证、凭据更新、错误凭据拒绝、资源移除阻断及入口用户计数。mihomo 仍使用现有活动连接采样，无法保证采集间隔内已关闭短连接的完整字节数；此测试在连接存活时采样，不将其宣称为精确的短连接计费。

# 中转变更影响预览

在现有单线路和多入口整组启停、删除之前，提供只读的资源影响清单和可选的配置条件校验。本轮仅后端/API，不重做 UI，不复用或合并原本独立的隧道资源。

## 接口

管理员会话可调用：

- `POST /inbounds/:id/relays/:rid/change-preview`
- `POST /inbounds/:id/relay-batches/:bid/change-preview`
- `POST /chains/:id/change-preview`：普通链路仅支持删除预览。

请求为 `{"action":"enable"}`、`{"action":"disable"}` 或 `{"action":"delete"}`。受管中转和整组的操作与原有接口一致；普通链路的更新仍使用原接口，但删除旧资源前也增加引用检查。

预览返回 `etag`，响应头同时包含相同的强 `ETag`。执行相应启停或删除操作时可以传 `If-Match`：

```http
POST /inbounds/INBOUND_ID/relays/RELAY_ID/change-preview
Content-Type: application/json

{"action":"delete"}
```

```http
DELETE /inbounds/INBOUND_ID/relays/RELAY_ID
If-Match: "预览返回的64位摘要"
```

客户端应原样使用响应中的引号和摘要。仅接受单个强 ETag，不接受 `*`、弱标签、多个标签或未加引号的值。摘要绑定接口范围、操作和选中线路，删除预览不能用于启停，也不能在单条、整组和普通链路接口之间混用。

预览后配置、发布入口、下发版本、相关资源或引用发生变化时，执行返回 412，需重新预览。存在不随选中线路一起删除的引用时返回 409，并列出引用资源。未传 `If-Match` 的旧调用继续兼容，但删除/重建链路资源的引用检查仍生效。普通链路更新不接受删除预览的 `If-Match`；如使用幂等键，重新预览后的新操作也应使用新的幂等键。

## 影响清单

响应包括：

- 选中的 `chainIds`、实际需改变的 `changedPaths`，以及所涉及节点的名称、状态和下发版本。
- 受管发布入口、出站、路由规则和实际服务账号的 ID，不返回账号凭据或隧道密钥。
- 受管转发生成的监听端口、TCP/UDP、公开/本地监听标记和隧道角色，不返回隧道认证或完整配置。
- 每个节点上其他线路的引用数量，以及操作后同一落地入站剩余的受管线路数和启用线路数。
- `relayOnly`、`sourceProtection` 与必要警示。删除最后一条启用线路不会自动关闭仅中转发布或来源保护，也不会自动开放落地直连。

资源 ID 清单表示选中线路拥有的资源。启停主要改变线路启用状态及生成配置，不代表这些数据库对象会被删除；删除才清理相应受管资源。`changedPaths=0` 的重复单线路状态请求不重复标记下发或写状态审计，与整组接口保持一致。

共享节点不等于共享隧道或共享凭据。清单按明确的线路/组标识划定范围，其他线路继续保留各自的监听和资源。停用、缺失或离线节点会提示，但预览不声称这些节点已经应用配置；剩余启用数量是配置状态，不是业务可用性检测。

## 引用保护

原先普通代理链删除或更新会直接清理自己的受管出站。现在链路删除/重建之前会检查存活配置：

- 出站组的成员、兜底和其他出站的下一跳引用。
- 入站直接绑定的出站。
- 节点路由和全局路由对这些出站的引用。
- 不在删除集合内的其他链路或出站对即将删除的服务账号的引用。

同一删除集合内的受管路由、出站不相互阻塞，避免将链路自己的正常内部引用误认为外部依赖。出现外部引用时不先删除部分资源，不自动改成直连或其他出口。`blocked` 专指这一类引用阻塞，不替代原有启用、协议、端口及来源保护校验。

保护范围是本轮接入的链路/中转操作。节点或入站整体删除仍沿用既有清理语义；这不是覆盖所有配置表和外部 SQL 写入的数据库外键机制，也不推断面板之外的客户端、脚本或其他服务器是否依赖某个监听端口。

## 一致性与权限

预览使用只读数据库快照；PostgreSQL 使用可重复读，预览不写线路、服务账号、下发版本、诊断状态或业务审计，不发送 Agent 命令。执行在现有事务中重新计算条件和引用，失败保持原有原子回滚语义。普通链路修改/删除在事务内重新锁定并读取当前链路，防止清理较旧快照中的服务账号。

摘要忽略网卡流量、心跳时间、系统指标和链路探测结果，避免正常采样使预览持续失效；地址、能力、配置版本、相关配置内容及引用变化仍会使预览失效。校验是对执行事务读取到的配置进行乐观比较，不承诺所有旧配置接口或面板之外的并发写入均由全局外键约束串行保护。

新接口默认仅管理员会话可访问，不自动开放给节点管理员或 API 令牌。预览和执行都不扩大原有操作权限；ETag 是配置比较值，不是授权令牌。

## 验证

覆盖单条和整组影响清单、共享节点隔离、隧道和服务账号凭据不回显、操作范围和动作绑定、412/409 拒绝及无副作用、心跳/流量/探测更新不影响摘要、重复状态请求不重复审计、各类外部引用阻塞，以及内部受管引用正常删除。现有多入口生命周期、来源保护及事务失败回滚测试继续适用。

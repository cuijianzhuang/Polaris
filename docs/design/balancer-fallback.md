# 均衡器之间回退

## 行为与配置

复用出站 `settings.fallback` 字段，不增加数据表。目标可以是同一节点的普通出站、均衡组、自动选择组或手动选择组，也可以是内置 `direct` / `block`（能力限制见下表）。成员列表只放主线路，备用组单独选择；各组保留自己的成员及均衡策略。

```text
入站 / 路由 → primary [hk-1, hk-2]
                全部不可用 ↓
             backup [jp-1, jp-2]
                全部不可用 ↓
             emergency [sg-1]
                全部不可用 ↓
             block（Xray，可选）
```

健康判断由节点上的内核执行，不依赖面板定时发布配置。主组仍持续被探测，恢复后新连接使用主组。现有 TCP / UDP 会话不迁移；真实连接失败不等同于每次都立即重试备用，切换等待内核探测结果刷新。手动选择组保持手动选择语义，作为备用时不会变成自动健康选择。

| 内核 | 组间回退 | 实现与限制 |
| --- | --- | --- |
| Xray | 支持 | `fallbackTag` → 127.0.0.1 上经 UUID 认证的内部 VLESS 入口 → 指定备用 `balancerTag`。支持多级及 `block` 终止回退 |
| mihomo | 支持 | 原组变为内部主组，对外保持原标签的 `fallback` 组，按 `[主组, 备用目标]` 顺序选择；两层主动探测以恢复主组。`block` 无法作为健康备用，禁止该配置 |
| sing-box | 暂不支持 | 原生 `urltest` 不能表达“主组全故障才用备用组”的优先级；保存和渲染均明确拒绝带 `fallback` 的组，避免静默忽略 |
| Hysteria2 | 不适用 | 仍只有其原有的直连 / 拦截 / SOCKS5 / HTTP 路由能力 |

节点安装了多个代理内核时，设置必须被这些内核共同支持。有 sing-box 时需清除 `fallback` 或换用 Xray / mihomo；存量含该字段的 sing-box 配置也会收到明确错误，应在升级前清理。未配置兜底的普通组保持原有行为。`direct` 表示允许节点直接联网；要求所有备用也故障后拒绝连接时，Xray 的末级组需显式选择 `block`。mihomo 的所有成员均故障后遵循其原生故障行为，不承诺 `block` 语义。

## Xray 路由与探测

`fallbackTag` 只能引用普通出站 handler，不能直接填写另一个均衡器标签。渲染时为每条组间回退边生成稳定的内部标签及认证 VLESS 桥接，并添加 `inboundTag → balancerTag` 路由。内部规则排在 API 规则之后、限速 / DNS / 用户规则之前，保证原始目标不变，避免回退后再次匹配原用户规则或再次进入限速器。生成标签避开已有入站 / 出站标签，且起始字符不与任何用户出站标签相同，避免 Xray 前缀 selector 将内部桥接误选成主成员。

内部入口仅监听 127.0.0.1，使用随机 UUID，内部账号不设置 email，防止 Xray 原生 loopback 继承用户上下文而重复累计用户流量。内部入口和出口的传输计数也不对面板上报。系统分配本机空闲端口，并避开配置中已有端口；端口和 UUID 在重复渲染、Agent 重启时从已有私有配置中复用。首次新增或移除桥接会改变入站配置，需要重载内核；后续故障切换不发布配置、不重启进程。VLESS 内部转发保留目标地址并支持 TCP / UDP，不向公网开放新入口。

随机 / 轮询组配置兜底时启用成员探测，否则内核一直认为候选可用，无法触发兜底。存在 leastLoad 时，所有需探测的成员共享 burstObservatory；其报告也包含其他策略需要的 Alive / Delay。避免同时注册两个 Observatory 功能而导致部分成员没有探测结果。

Xray 同节点的组共享探测地址（沿用最后一个显式配置的地址，默认 gstatic generate_204）及最短探测间隔，各组建议使用同一个地址。空白间隔视为 1m。mihomo 各组单独使用自己的地址 / 间隔。配置字段显示的是探测周期，不是故障切换 SLA。

默认路由若直接指向均衡组，补一条最终 `balancerTag` 规则，不能仅将均衡器标签当作第一出站。

## 校验与编辑保护

- 对成员、兜底、detour 构成的完整依赖图检查引用存在、重复成员、自引用和间接循环；跨节点目标必须先创建成本节点的 node_ref 出站。
- 禁止主成员同时作为兜底；不将备用组混入主组成员列表。
- 界面按备用组 / 普通出站分类选择，过滤会形成循环的候选，显示回退路径；API 独立复核，不能靠手工请求绕过。
- 被成员、兜底、detour、入站或路由引用的出站，不能直接改标签或删除；先解除引用，再删除。
- 手工保存和删除在事务中执行；本机互斥加 PostgreSQL 每节点事务 advisory lock，避免不同面板实例并发提交相反的回退边。存量非法图在内核渲染阶段仍会被拒绝。

## 验证

图校验与 API 测试覆盖循环、跨节点引用、空成员、重复成员、错误更新不落库、改名和删除保护及内核能力限制。真实 Xray / mihomo 集成测试仅使用本地模拟 HTTP 出站，验证主组部分故障、全部故障、多级回退和主组恢复，不依赖第三方网络。Xray 使用真实认证用户，对比直达、一级回退、二级回退的上传 / 下载计数，确认不会重复扣量。

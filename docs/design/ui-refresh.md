# 控制台 UI 打磨与主题方向

## 本轮实现

主框架采用更克制的工作台布局：窄侧栏、独立命令栏、当前位置与有最大阅读宽度的内容区。保留现有导航、侧栏折叠、快捷搜索和手机菜单；减少装饰性渐变、彩色图标块与悬浮位移。卡片、表格、按钮与字体层级使用统一中性色，强调色用于主要操作和真正的状态信息。

仪表盘先展示核心指标，运维汇总改为分隔式信息布局，减少嵌套卡片。节点和用户健康提示限定为对应范围，不再用“一切正常”概括仍可能存在运维问题的系统。探针卡片继承面板的表面色、文本色和强调色，消除与深色/黑金主题的割裂；公开状态页保留独立的配色。

设置页在窄屏恢复横向标签导航，直接显示分区并支持滑动；切换分区或通过链接直达时，当前标签自动滚入可见区域，避免原生下拉浮层遮住表单。外观设置按主题风格、模式、配色的顺序展示，配色按钮有名称与选中标记。实时预览使用实际主题变量，示例数据有明确标识。黑金等专属主题继续受原许可证限制；选中后模式如实显示为固定深色，切回基础风格后恢复之前的自选模式和配色。

新浏览器默认采用浅色暖灰琥珀及跟随风格的配色，已有浏览器保存的模式、配色与主题不重置。触屏输入框使用 16px 字号，减少 iOS 聚焦时缩放；主题选择保留可见的键盘焦点和足够的触控面积。

## 主题方向与落地范围

| 方向 | 表面 / 背景 | 强调色 | 适合用途 | 优先级 |
| --- | --- | --- | --- | --- |
| 雾白石墨 | `#FCFCFD` / `#FFFFFF`，灰阶分层 | 石墨 `#27272A`，交互文字保持高对比 | 日常管理、表格和长时间阅读 | 已实现，保留为免费基础风格 |
| 午夜冰青 | 深色 `#0D1524` / `#151F30`；浅色 `#F3F7FA` / `#FCFEFF` | 深色冰青 `#67D8CF`，浅色青 `#197C78` | 夜间运维、探针和资源监控 | 已实现，免费基础风格 |
| 暖灰琥珀 | 暖白 `#F7F6F2` / `#FFFEFB` | 琥珀 `#995B16` | 偏好柔和暖色的管理界面 | 已实现，新浏览器默认 |

按已选定的暖灰琥珀方向新增免费 `warm` 风格及 `amber` 强调色。暖白背景、暖白卡片、石色导航与表单边框共同构成层次，深色模式采用暖炭灰表面与浅琥珀操作色；支持跟随系统。导航、输入框、图表、模态框、悬停、禁用与焦点状态均继承同一套主题变量，管理员探针也同步继承。上下行使用琥珀与石灰色区分，仪表盘仍保留实线/虚线，避免与橙色警告语义混淆。

雾白石墨、暖灰琥珀、午夜冰青均为免费基础风格，支持浅色、深色、跟随系统。午夜冰青的导航、卡片、输入框及弹层使用蓝灰层次，深色模式搭配冰青，浅色模式提高青色深度以保持按钮文字对比度。图表上行使用淡紫，与冰青下行区分；健康、警告及故障沿用语义色。

默认“跟随风格”会自动采用石墨、琥珀或冰青强调色；自选配色可跨风格保留，点击“跟随风格”可恢复当前风格的推荐配色。切换风格不覆盖已选模式，已有浏览器明确保存的配色与风格也不重置。黑金继续使用原有专业版授权与固定深色配色；三套免费风格不会因专业版状态变化而失效。

所有主题沿用相同的信息层级和交互。绿色、橙色、红色始终保留健康、注意、故障的语义；不能把品牌强调色与状态色混用。避免满屏高饱和卡片、装饰性光晕和以透明度牺牲可读性的玻璃效果。黑金主题的授权范围保持原规则，三套基础风格免费。

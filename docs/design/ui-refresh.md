# 控制台 UI 打磨与主题方向

## 本轮实现

主框架采用更克制的工作台布局：窄侧栏、独立命令栏、当前位置与有最大阅读宽度的内容区。保留现有导航、侧栏折叠、快捷搜索和手机菜单；减少装饰性渐变、彩色图标块与悬浮位移。卡片、表格、按钮与字体层级使用统一中性色，强调色用于主要操作和真正的状态信息。

仪表盘先展示核心指标，运维汇总改为分隔式信息布局，减少嵌套卡片。节点和用户健康提示限定为对应范围，不再用“一切正常”概括仍可能存在运维问题的系统。探针卡片继承面板的表面色、文本色和强调色，消除与深色/黑金主题的割裂；公开状态页保留独立的配色。

设置页在窄屏使用分区选择器，代替难以发现完整选项的横向导航。外观设置按主题风格、模式、配色的顺序展示，配色按钮有名称与选中标记。实时预览使用实际主题变量，示例数据有明确标识。黑金等专属主题继续受原许可证限制；选中后模式如实显示为固定深色，切回基础风格后恢复之前的自选模式和配色。

新浏览器默认采用浅色暖灰琥珀，已有浏览器保存的模式、配色与主题不重置。触屏输入框使用 16px 字号，减少 iOS 聚焦时缩放；主题选择保留可见的键盘焦点和足够的触控面积。

## 主题方向与落地范围

| 方向 | 表面 / 背景 | 强调色 | 适合用途 | 优先级 |
| --- | --- | --- | --- | --- |
| 雾白石墨 | `#FCFCFD` / `#FFFFFF`，灰阶分层 | 石墨 `#27272A`，交互文字保持高对比 | 日常管理、表格和长时间阅读 | 已实现，保留为免费基础风格 |
| 午夜冰青 | 午夜蓝 `#0D1524` / `#151F30` | 冰青 `#67D8CF` | 夜间运维、探针和资源监控 | 下一套完整深色主题 |
| 暖灰琥珀 | 暖白 `#F7F6F2` / `#FFFEFB` | 琥珀 `#995B16` | 偏好柔和暖色的管理界面 | 已实现，新浏览器默认 |

按已选定的暖灰琥珀方向新增免费 `warm` 风格及 `amber` 强调色。暖白背景、暖白卡片、石色导航与表单边框共同构成层次，深色模式采用暖炭灰表面与浅琥珀操作色；支持跟随系统。导航、输入框、图表、模态框、悬停、禁用与焦点状态均继承同一套主题变量，管理员探针也同步继承。上下行使用琥珀与石灰色区分，仪表盘仍保留实线/虚线，避免与橙色警告语义混淆。

雾白石墨继续作为免费基础风格；两套基础风格允许独立自选强调色，切换风格不覆盖已选模式及配色。黑金继续使用原有专业版授权与固定深色配色；免费风格不会因专业版状态变化而失效。午夜冰青仍是后续方案，尚未发布。

所有主题沿用相同的信息层级和交互。绿色、橙色、红色始终保留健康、注意、故障的语义；不能把品牌强调色与状态色混用。避免满屏高饱和卡片、装饰性光晕和以透明度牺牲可读性的玻璃效果。黑金主题的授权范围保持原规则，新增暖灰风格免费。

## 验证范围

前端类型检查、生产构建与中英文键值检查；浏览器验证明暗与系统模式、配色持久化、已有偏好保留、免费主题不受许可证影响、专属主题锁定/恢复、琥珀主要按钮明暗对比度不少于 4.5:1、命令搜索、移动端设置导航、侧栏折叠和主要页面横向溢出。视觉记录使用合成示例数据，不能替代生产业务验收。

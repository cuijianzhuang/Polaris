# 管理界面：运维与中转功能接入

本轮为已经存在的后端能力增加管理界面，保持原来的节点、入站、仪表盘和设置结构。没有新增协议、可靠通知队列、共享隧道或转发商品模型；这些仍按功能对照文档作为后续任务。

## 功能入口

| 入口 | 可操作内容 | 对应接口 |
| --- | --- | --- |
| 仪表盘 → 运维汇总 | 线路业务、采样和交付异常计数；展开异常明细 | `GET /stats/overview` 的 `operational` |
| 节点 → 节点网络检测 → 测试点策略 | 继承全局、独立、关闭；省市运营商预设和自定义目标；展示生效目标 | `/nodes/:id/probe-policy` |
| 节点 → 节点网络检测 → 回程与定时检测 | IPv4/IPv6 手动检测、定时策略、运行状态、历史分页和地址族/目标筛选 | `/nodes/:id/route-trace`、`route-schedule`、`route-traces` |
| 回程历史 → 详情 | 路径变化摘要、上次/当前逐跳地址对照和 ASN、国家省市、数据库版本、原始输出 | `/nodes/:id/route-traces/:traceId` |
| 设置 → 网络检测 | ASN 与城市 MMDB 独立从仓库获取、上传/启用、实例状态、版本及本地 IP 验证；城市库支持 gzip | `/tools/route-asn/*`、`/tools/route-geo/*` |
| 设置 → 通知策略 | 运维事件×渠道开关、合并窗口、按节点/渠道维护静默 | `/notifications/policy` |
| 入站 → 授权与出口；入站模板编辑 | 五种出站 IP 策略，随表单保存 | 原有入站、预览及模板接口的 `outboundIPStrategy` |
| 入站 → 中转与访问控制 | 仅中转发布、来源限制、PROXY v1/v2、按节点覆盖 NAT/专线来源 | 原有入站接口的 `relayOnly`、`relayAccess` |
| 入站列表 → 中转；入站编辑 → 中转管理 | 多入口创建预览、单条和整组启停/删除、组详情、独立名称和分享地址修改 | `/inbounds/:id/relays/*`、`relay-batches/*` |
| 中转管理 → 网络诊断 / 真实业务诊断 | 独立展示网络检查与真实业务验证，可选自定义 TCP/UDP 目标 | `/diagnose`、`/diagnose/business` |
| 链路与路由 → 删除链路 | 先展示删除影响，阻断外部引用，带预览版本执行 | `/chains/:id/change-preview`、`DELETE /chains/:id` |

## 交互与边界

- 沿用管理员会话和原接口权限。节点管理员界面不展示新增运维配置，也不请求这些管理接口。界面隐藏不替代服务端鉴权。
- 测试点默认继承现有策略，不在打开页面时执行网络命令或创建定时任务。独立目标提交仅含名称、运营商和地址，不回传服务器生成的目标 ID。
- 回程目标为对应地址族的公网 IP 字面量。定时任务默认关闭，间隔为 5–1440 分钟；显示全局探测暂停状态及 Agent 能力。保存携带 `expectedRevision`，遇到配置冲突提示刷新，不盲目覆盖。
- 历史区按需读取详情；列表每 15 秒刷新，最多每页 20 条，通过游标查看更早记录。ASN 信息使用历史中保存的结果；界面不重新查询或猜测商业线路等级。
- ASN 使用原始二进制上传，保留既有登录失效处理和敏感操作复核重试。首次上传不会自动开启；文件大小限制为 64 MiB。界面分别展示策略开关和当前实例是否实际生效，并说明多实例安装及备份边界。
- 通知矩阵从后端事件元数据读取默认值。`route_changed` 各渠道默认关闭，未改动的渠道不会被保存时自动开启。维护时间按浏览器本地时区输入，转换为带时区的绝对时间；未选节点/渠道表示全部。
- 中转创建先预览端口和提醒，确认仅提交冻结计划 token；改变创建选项即丢弃旧预览。单条/整组启停或删除，以及普通链路删除，都携带预览返回的强 `If-Match`。引用阻塞时禁止确认，版本变化时要求重新预览。
- 仅中转发布不等于防火墙隔离；来源限制和 PROXY 的要求单独说明。来源覆盖按节点配置，空白行在保存前清理。
- 真实业务诊断有明确确认提示：正常回收临时身份，清理失败可能重启共享 Xray 并中断连接。网络可达、未测试、未就绪和不支持都不展示成真实业务成功。自定义目标结果不覆盖概览标准记录。
- 中转管理抽屉通过 portal 显示，避免从入站编辑中打开时被父抽屉动画裁切。表格在手机端局部滚动，不扩大整页宽度；新增文本提供中英文翻译。

## 验证

前端执行 `npm run build`、`npm run i18n:check`。浏览器回归使用模拟 API 检查真实页面交互和请求：测试点字段、定时版本、回程与 ASN 历史、渠道默认值、维护时间、原始二进制上传、多入口冻结 token、操作 ETag、引用阻塞、真实诊断语义、入站与模板字段保存、嵌套抽屉、冲突、节点操作员限制，以及英文和自定义管理员路径。

可重复运行的脚本为 `web/scripts/operations-ui-smoke.py`。需 Python Playwright 与 Chromium；先在 web 目录启动 `npm run dev -- --host 127.0.0.1 --port 5187`，再在仓库根目录运行：

```sh
POLARIS_WEB_TEST_URL=http://127.0.0.1:5187 python3 web/scripts/operations-ui-smoke.py
```

可通过 `POLARIS_CHROMIUM_BIN` 指定浏览器路径、`POLARIS_UI_ARTIFACTS` 指定截图目录。脚本覆盖 320/390/1440 像素宽度，浏览器请求由固定 API 样例拦截，不连接生产服务。

浏览器测试不是公网 traceroute 或真实代理连通性验收；这些由后端已有测试和部署环境验收分别覆盖。

城市归属接口、文件边界和快照语义参见[国家省市归属说明](route-geo.md)。
